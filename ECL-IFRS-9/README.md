# Expected Credit Loss (IFRS 9)

**Status:** In progress

An illustrative expected credit loss (ECL) model for trade receivables, covering ageing analysis, historical loss rates, forward-looking adjustment and the resulting loss allowance.

## Planned contents

- `ECL_model.xlsx` - the working model
- `ECL_methodology.pdf` - short methodology note

## Data privacy

All data will be anonymised or illustrative. No confidential employer or third-party information will be included.
